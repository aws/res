# Security

## Reporting a vulnerability

Report a suspected security issue in RES through the
[AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/).

Please do not open a public GitHub issue for a security report.

AWS publishes security advisories for RES as GitHub Security Advisories on this repository.

## After support ends

2026.09 is the final release of RES. Support ends on 2027-09-30, its End of Support Life, after which no
version of RES falls under the AWS support policy. [`SUPPORT.md`](./SUPPORT.md) covers the dates and the
policy.

If you are running a fork, report to its maintainer. See [`FORKS.md`](./FORKS.md).

Amazon DCV and the AWS services RES runs on have their own lifecycles, so the AWS vulnerability reporting
page above is the route for a problem in one of those rather than in RES.
