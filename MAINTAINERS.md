# Maintainers

The RES team at AWS supports RES until the End of Support Life of 2026.09, the final release.
[`SUPPORT.md`](./SUPPORT.md) has the dates.

This file names no individual maintainers. Anything you would send to a maintainer should go through the
channels in [`SUPPORT.md`](./SUPPORT.md), or [`SECURITY.md`](./SECURITY.md) for a vulnerability.

## Contributions

Pull requests opened here are not merged. If you need a change to RES, fork the repository and make it
there. See [`FORKS.md`](./FORKS.md).

The issue tracker is open while the repository is open. [`SUPPORT.md`](./SUPPORT.md) has the support
route and the dates.

## After support ends

[`FORKS.md`](./FORKS.md) covers finding and evaluating a fork.
