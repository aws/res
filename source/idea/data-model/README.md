# Directories

## datamodel

This library contains RES data models and serializers that are auto-generated from Smithy models that can be installed and utilized by various computational components in RES.

### models

Auto-generated Python data model classes from Smithy service definitions. These provide type-safe structures for RES API requests, responses, and domain objects.

### serializers

Auto-generated serializers for converting between Python models and JSON/dictionary formats. Handles data transformation for API communication.

## datamodel_meta

Defines basic meta data for the datamodel package

## tests

Contains tests for the datamodel library
